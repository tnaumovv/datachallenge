# Проверка и защита CQA за пять минут

## Подготовка

Сначала выполните `npm ci`, `npm test`, `npm run typecheck`, `npm run build`, `npm run smoke`. Затем `npm start` и откройте `http://127.0.0.1:3000/dialogs`. Существующий `.env` не заменяйте.

В обычном режиме новая оценка требует настроенных `AI_PROVIDER`, `GEMINI_API_KEY`, `GEMINI_MODEL` и доступной квоты. Сохранённые результаты читаются без нового вызова модели. После изменения переменных перезапустите сервер.

Для изолированной проверки интерфейса без ключа используйте `npm run demo:web`. Это временная база в памяти, вымышленные диалоги и заранее заданные ответы. Видимая пометка «Демо · вымышленные данные и оценки» обязательна; этот режим не доказывает качество Gemini и не использует рабочую SQLite-базу.

Подготовьте заранее:

- Сохранённый настоящий результат и транскрипт для показа доказательств. Не импортируйте предварительную ручную разметку как результат модели.
- Учебный результат 85,38 для объяснения арифметики и апелляции.
- Настоящий результат с `grossViolation=true`, если он доступен. Проверьте сам флаг и цитату, не полагайтесь на исходный номер диалога.
- Звонок с доступной аудиоссылкой. Если запись недоступна, прямо покажите это состояние. Абсолютный timestamp не означает подтверждённое время относительно начала аудио.
- Настроенную квоту для новой оценки после изменения критерия. При отсутствии доступа можно показать сохранение версии, но успешный новый вызов остаётся непроверенным.

Не запускайте весь DEV во время пяти минут. Неизвестную контрольную группу импортируйте тем же интерфейсом, меняя только `groupId`; отдельная структура для контроля не нужна.

## Сценарий

| Время | Действия | Основная мысль |
| --- | --- | --- |
| 0:00–1:00 | Открыть «Диалоги», показать язык, канал и группу. Открыть подготовленный диалог и транскрипт. На звонке показать плеер. | Оценивается оператор; client, bot и system сохраняются как контекст. DEV содержит 65 записей: 60 чатов и пять звонков. |
| 1:00–2:10 | В явно обозначенном учебном режиме показать результат 85,38, два N/A, консультацию 15 и ведение диалога 7. Нажать доказательство и показать исходную реплику/проверенный участок. | Сервер считает `100 × 55,5 / 65 = 85,38`. N/A исключает вес из обеих сумм. Наличие цитаты проверяет код; смысл решения проверяется отдельно. |
| 2:10–3:00 | Открыть заранее проверенный сохранённый результат с грубым нарушением, если он доступен. Показать флаг и подтверждающую реплику; вернуться к учебному результату. | Gross хранится отдельно и не обнуляет числовой итог. Сохранённый результат не является новым онлайн-вызовом. |
| 3:00–4:00 | У учебной консультации 15 подать апелляцию с комментарием. Через «Апелляции» открыть её, изменить ответ на 20, ввести причину и сохранить. Показать исходные 85,38 и итоговые 93,08. | Изменяется один эффективный ответ; исходные ответы и история остаются. Пересмотр не вызывает Gemini. |
| 4:00–5:00 | В «Чек-листах» изменить вес ведения диалога 15 → 20 или добавить критерий, сохранить новую версию. Выбрать её в карточке и запустить оценку. Открыть старую оценку с прежней версией. | Конфигурация меняется через UI. Старые результаты связаны с прежней версией. Пока задача queued/running, не объявлять её завершённой. |

Пример комментария к учебной апелляции: «В учебном диалоге клиент подтвердил решение вопроса». Пример причины решения: «В этом вымышленном примере все существенные вопросы закрыты, меняю консультацию на 20».

## Перед сдачей

Проверьте перезапуск с сохранением результатов, повтор импорта без дубликатов, прямую ссылку на карточку/доказательство, ошибку модели и явный retry, а также сохранение новой версии. Повтор выполненной оценки может вернуть кэш; для действительно нового запроса предусмотрен `force=true`.

Три отдельных решения ручной разметки утверждены пользователем; 11 выделенных спорных решений ещё ожидают проверки. Ни один полный диалог из `reference-set-v1` пока не является согласованным человеческим Ground Truth. Эти локальные файлы не публикуются.

Проверки Мерея и их ограничения доступны в [qa/gemini/README.md](../qa/gemini/README.md). Есть успешные сохранённые языковые примеры, но есть и ошибки квоты, языка объяснений и смысловые расхождения. Нельзя объявлять точность на неизвестном контроле по этим примерам. Для платного API укажите фактическую модель и стоимость всех попыток; при неизвестном usage полный расход остаётся неизвестным.

До стоп-кода команда передаёт организаторам ссылку на публичный репозиторий. Этот документ ничего не отправляет. На T+24 зафиксируйте последний разрешённый commit; после freeze используйте готовый UI для данных и чек-листа в рамках правил организаторов.
