```sh
npm run export:results -- \
  --database runtime/cqa.sqlite \
  --group PROD \
  --source-group 'ФАКТИЧЕСКИЙ_GROUP_ID' \
  --output results/prod/results.json \
  --team-name 'Paradox' \
  --checklist-version 'ID_СТАНДАРТНОЙ_ВЕРСИИ'
```

До стоп-кода проверьте 10 исходных ID и число `ok`/`error`, затем сделайте commit и push файла PROD. Ссылка на публичный репозиторий должна быть передана организаторам самой командой. Для демонстрации изменения веса/добавления критерия создавайте отдельную версию: стандартные DEV/PROD экспортируются с исходными шкалами и весами.
